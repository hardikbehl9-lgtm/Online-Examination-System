# Online-Examination-System
A Python Tkinter-based Online Examination System featuring MCQ tests, countdown timer, automatic evaluation, and result generation. Developed as an academic project using Python and Tkinter.

## About the Project

The Online Examination System allows students to participate in computer-based examinations through a graphical user interface. It aims to make the examination process easier with automatic evaluation and result generation.

## Features

- Student login
- Interactive examination interface
- Multiple-choice questions (MCQs)
- Countdown timer
- Next and Previous question navigation
- Automatic answer evaluation
- Result and score generation

*Note: Features will be updated as development progresses.*

## Technologies Used

- **Python** – Main programming language
- **Tkinter** – Graphical User Interface (GUI)

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

5. The Online Examination System will launch.

## Requirements

- Python 3.x
- Tkinter (included with most standard Python installations)
